Who it's for

For GCs juggling waivers on every draw

If you're the one chasing waivers before a draw goes in, this is for you. A missing conditional holds up the owner's check, and a missing unconditional leaves you exposed on the next one.

Log each sub payment and the file shows which waiver you still need. Before you submit a draw, it checks that every sub's conditional is in. When it's time to ask for paperwork, the request list builds itself with each vendor's email.

Good to know

This tracks waivers. It doesn't supply them.

Lien waiver rules and forms are set by each state. Where your state requires its own statutory forms, use those. Waiver forms aren't included in this file.

This is a tracker for your records, not legal advice. If you're unsure what your state requires, check with an attorney or your state's rules.
